# SHELLFORGE

A Bash-like shell written in C language.

## Project Milestones

### Milestone 1: Initial ShellForge Framework
- Created basic ShellForge project structure
- Created `src`, `include`, `tests`, and `docs`
- Created initial `main.c`
- Created Makefile
- Basic shell execution

### Milestone 2: Tokenizer
- Tokenizes the line entered by the user
- Separates the input into individual words/tokens
- Stores tokens for further processing

### Milestone 3: Organizer
- Organizer acts as a placeholder for all words of the input line
- Uses a user-defined `structure`
- Structure stores different fundamental data types
- Example: Employee structure with employee number, name, and salary
- Uses structure pointers and the `->` operator to access members
